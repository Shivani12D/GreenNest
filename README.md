# GreenNest 🌱

GreenNest is a **smart plant management system** where users can explore, buy, and manage plants online.  
The project is designed with a **nature-inspired, minimalist, and fresh theme** to provide a seamless plant shopping experience.

---

## 🚀 Features

- User-friendly interface
- Plant catalog with images and details
- Shopping cart functionality
- Responsive design (works on desktop, tablet, and mobile)
- Search and filter options for plants

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Django (Python)  
- **Database:** SQLite (or PostgreSQL for production)
